# LLM-Assisted Development: Project Overview and Credits

## Academic Context

**Project:** Unity MSc Thesis Project - Biodiversity Visualization System
**Institution:** UAL (University of the Arts London)
**Development Method:** Human-AI Collaborative Programming
**AI Assistant:** Claude (Anthropic) via Claude Code
**Date:** December 2024

---

## Project Objective

This project demonstrates the integration of:
1. **Real-world biodiversity data** from iNaturalist API
2. **3D geospatial visualization** using Mapbox Unity SDK
3. **Scientific metrics** (Simpson's Biodiversity Index)
4. **Dynamic procedural generation** based on ecological data
5. **Educational interaction** through networked observation display

---

## LLM-Assisted Development Approach

### Development Philosophy

This project was developed using a **collaborative human-AI approach** where:
- **Human (Developer):** Provided domain knowledge, project requirements, design decisions, and testing
- **AI (Claude):** Provided implementation strategies, code generation, debugging assistance, and documentation

### Key Methodologies

1. **Iterative Problem-Solving**
   - Breaking complex features into manageable components
   - Incremental testing and refinement
   - Continuous documentation throughout development

2. **Pattern Recognition**
   - Identifying common Unity/C# patterns
   - Adapting solutions from similar problems
   - Following established SDK conventions (Mapbox, Unity)

3. **Documentation-Driven Development**
   - Creating comprehensive guides alongside code
   - Explaining "why" not just "how"
   - Academic-level detail for reproducibility

## Core Components Developed

### 1. Biodiversity Spawning System
**Purpose:** Spawn vegetation based on real biodiversity data
**Key Innovation:** Delayed spawning after observation data loads
**Methodology:** Event-driven architecture with coroutine monitoring

### 2. UI Canvas Independent Scaling
**Purpose:** Maintain readable UI regardless of prefab scale
**Key Innovation:** Override Unity's transform hierarchy inheritance
**Methodology:** Direct `localScale` manipulation

### 3. Biodiversity Score Management
**Purpose:** Calculate and visualize Simpson's Diversity Index
**Key Innovation:** Real-time grid-based ecological calculations
**Methodology:** Spatial indexing with cellular grid system

### 4. Manual Control System
**Purpose:** Override automatic systems for testing/debugging
**Key Innovation:** ScriptableObject control from MonoBehaviour
**Methodology:** Adapter pattern for asset-component communication
